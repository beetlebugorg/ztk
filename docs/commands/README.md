# The ztk:: commands

ztk has the commands of Tk, and the commands below in the namespace `ztk::`. Each one has its reference here or in the guide of its area.

| Command | What it does | Reference |
|---|---|---|
| `ztk::animate` | Animates the options of a widget, with easing. | [Animation](../animation.md#ztkanimate) |
| `ztk::style`, `ztk::class` | Loads a stylesheet, and sets the style classes of a widget. | [Styling and themes](../styling.md) |
| `ztk::tooltip` | Shows a text when the pointer rests on a widget. | [Frames, labels, and buttons](../widgets/basic.md) |
| `ztk::terminal` | A terminal widget on libghostty-vt. | [Terminal](../widgets/terminal.md) |
| `ztk::debug` | Gives the source of an option, the geometry chain, traces, and visual diffs. | [Debugging](../debugging.md) |
| `ztk::tree`, `ztk::snapshot`, `ztk::inject` | Read the widget tree, render the window to an image, and send input, for tests and agents. | [For agents](../agents.md) |
| `ztk::limit`, `ztk::clock` | Run one script with lower limits, and read or set the animation clock. | [ztk::limit](limit.md) |
| `ztk::dnd`, `tkdnd::drop_target` | Drags to other apps and drops from them. | [ztk::dnd](dnd.md) |
| `ztk::tray`, `ztk::has` | A tray icon, and a test for each platform feature. | [ztk::tray](tray.md) |
| `ztk::taskbar`, `ztk::recent`, `ztk::hotkey` | The taskbar or Dock button, the recent documents, and global shortcuts. | [ztk::taskbar](taskbar.md) |
| `ztk::win::backdrop`, `ztk::win::jumplist`, `ztk::win::thumbbar` | APIs of Windows. | [ztk::win](win.md) |
| `ztk::mac::dockmenu`, `ztk::mac::tabbing` | The menu of the Dock icon, and the window tabs of macOS. | [On macOS](../macos.md#direct-apis-of-macos) |
