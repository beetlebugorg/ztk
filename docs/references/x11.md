# X11

The X11 client (`src/platform/x11.zig`) speaks the X Window System protocol over the Unix socket of the server. It links no library. This page lists the documents that the code follows.

| Source | License | Use |
|---|---|---|
| "X Window System Protocol, Version 11" (X.Org) | Specification (MIT) | The connection setup and its reply, the byte order, `CreateWindow`, `MapWindow`, `ConfigureWindow`, `InternAtom`, `ChangeProperty`, `CreateGC`, `PutImage` with `ZPixmap`, `GetKeyboardMapping`, the predefined atoms, the event and error formats, and the key and button state bits |
| "Inter-Client Communication Conventions Manual" (X.Org) | Specification (MIT) | `WM_PROTOCOLS` and `WM_DELETE_WINDOW`, `WM_NAME`, `WM_CLASS`, and `WM_NORMAL_HINTS` with `PMinSize` |
| "Extended Window Manager Hints" (freedesktop.org) | Specification | `_NET_WM_NAME` of type `UTF8_STRING`, and `_NET_WM_ICON` of type `CARDINAL` for `wm iconphoto` |
| "X Display Manager Control Protocol", the section on the authority file format, and the `Xau` file format notes | Specification (MIT) | The entries of the authority file (`XAUTHORITY`) and `MIT-MAGIC-COOKIE-1` |
