# Security

ztk is experimental and has no release. Do not use it to run scripts from a source that you do not trust.

The plan has these rules for later code:

- The ztk library turns on no capability of ztcl.
- Only the `ztk` program turns on a capability, from a flag.

## Report a problem

Use a private report through the GitHub **Security** tab of [beetlebugorg/ztk](https://github.com/beetlebugorg/ztk/security/advisories/new). Include a script that shows the problem.
